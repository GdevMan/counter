# Counter

A small C counting tool with a secret built-in game and achievements.

## Features
- Counting (duh)
- Secret built-in game
- Unlockable achievements
## Installation
1. Clone or download this repository.
2. Navigate to the src directory.
3. Compile the program:
bash
```gcc main.c game.c achivements.c sls.c -o counter```

4. Run the program:
bash
```./counter```

## Usage

- To start counting, run:

bash
```./counter 10 "Done!"```


- This starts the counter with 10 and displays "Done!" as the completion message.

## Requirements
- GCC
- Linux (or another compatible environment)
- Minimum 50 IQ
